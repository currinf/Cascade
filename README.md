## Resources
[ChoiceScript intro](https://www.choiceofgames.com/make-your-own-games/choicescript-intro/)

## How to run/test the game
1. Install [Node](https://nodejs.org/en) if you haven't 
2. Clone this repo
3. Run `run-server.bat`
4. This should open `web/index.html` in your browser -- refresh the page to see changes reflected

## To update the game:
1. Edit the text files in `web/mygame`
